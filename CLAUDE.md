# Versegraph (site name: Forbidden Knowledge)

Nobler Works open-source demo, branded "Forbidden Knowledge" since 2026-11-01: lost civilizations, secret societies, banned books and Bible codes, each claim checked against sources (cross-refs, scroll timeline, ladder + daily quiz, myths, theories, map, extra-canonical texts + readers, papal timeline and legends, Egypt/Masons/Rosicrucians, honest ELS search). Prototype; no cloud.

- `site/index.html` is the whole app; `site/data/` is generated by `scripts/build_data.py` (gitignored).
- Published as artifact https://claude.ai/artifact/DfW1Z7Bpsi1CB5m8SgeTXn - republish `site/index.html` with every `site/data/*` file (16, incl. `world.json`).
- Keep the OpenBible CC BY attribution in the footer. Code Breaker always shows chance baselines; never present ELS hits as meaningful.
- Myth and canon cards are factual claims: verify against the text (or a cited source) before adding; evidence counts are computed live.
- Public site: `scripts/deploy-pages.sh` -> gh-pages -> versegraph.noblerworks.com (Route 53 CNAME in NW, like ironsight./wargames.).
